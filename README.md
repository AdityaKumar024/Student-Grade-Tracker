# Student Grade Tracker

## About the Project
Student Grade Tracker is a Java-based console application developed as part of my Java Programming Internship at CodeAlpha.

The main purpose of this project is to manage student marks and generate a performance summary. It displays student names and marks and calculates the average, highest, and lowest marks.

## Features
- Store student names and marks.
- Validate marks within the range of 0 to 100.
- Display all students and their marks.
- Calculate average marks.
- Find the highest marks.
- Find the lowest marks.
- Generate a student performance summary.

## Technologies Used
- **Programming Language:** Java
- **Input:** Java Scanner class
- **Concepts:** Arrays, Loops, Conditional Statements, Methods, and Basic Input Validation

## How to Run the Project

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in your terminal or Java IDE.
4. Compile the Java file:

   `javac StudentGradeTracker.java`

5. Run the program:

   `java StudentGradeTracker`
